# yAmcHer Posting Services — Installation Guide

## 1. Download the application

1. Visit the [official downloads page](https://github.com/yAmcHerism/yamcher-posting-releases/releases/latest).
2. Under **Assets**, download `yAmcHer-Windows.zip`.
3. Wait for the download to finish.

## 2. Extract the ZIP file

1. Open your Windows **Downloads** folder.
2. Right-click `yAmcHer-Windows.zip`.
3. Select **Extract All...**.
4. Choose a folder where you want to keep the application.
5. Click **Extract**.

Keep the extracted application files together in the same folder.

## 3. Start the application

1. Open the extracted folder.
2. Find `yAmcHer.exe`.
3. Double-click it to launch the application.
4. Follow the instructions displayed by the app.

If Windows displays a security warning, verify that you downloaded the application from the official releases page. Do not bypass a warning unless you have verified the file and understand the risk.

## 5. Troubleshooting

**The application does not open**
- Make sure you extracted the ZIP before running the application.
- Keep all files from the extracted folder together.
- Try launching `yAmcHer.exe` again.
- If the problem continues, contact support and include the error message.

**The download does not start**
- Return to the [official releases page](https://github.com/yAmcHerism/yamcher-posting-releases/releases/latest).
- Under Assets, click `yAmcHer-Windows.zip`.

**I need a newer version**
- Visit the [official releases page](https://github.com/yAmcHerism/yamcher-posting-releases/releases/latest) to check for the latest release.
- Follow the instructions provided with that release.
